## Что нужно сделать сейчас 🔧

### 1. Установить зависимости

```bash
cd telegram-bot
pip install -r requirements.txt
```

Или если используешь виртуальное окружение:
```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

pip install -r requirements.txt
```

### 2. Настроить `.env` файл

Создай файл `.env` в папке `telegram-bot/` (скопируй из `.env.example`):

```bash
cp .env.example .env
```

Затем открой `.env` и заполни следующие поля:

**ОБЯЗАТЕЛЬНО:**
- `BOT_TOKEN` - уже заполнен (***REMOVED_BOT_TOKEN***)
- `API_KEY` - секретный ключ для вашего API сервера генерации ключей
- `API_URL` - URL вашего API (например: `https://your-server.com/api/v1/generate-license`)
- `ADMIN_ID` - ваш Telegram ID (можно узнать у бота @userinfobot)

**ОПЦИОНАЛЬНО:**
- `OWNERS_CHAT_LINK` - ссылка на чат владельцев
- `INSTALLATION_LINK` - ссылка на установку расширения

### 3. Как узнать свой Telegram ID?

Напиши боту @userinfobot в Telegram - он покажет твой ID.

### 4. Проверить API сервера

Убедись, что ваш API сервер:
- Принимает POST запросы на `/api/v1/generate-license`
- Требует заголовок `Authorization: Bearer {API_KEY}`
- Принимает JSON: `{"user_id": "...", "username": "..."}`
- Возвращает JSON: `{"success": true, "license_key": "AEGIS-XXXX-XXXX-XXXX", "expires_at": null}`

### 5. Запустить бота

```bash
python bot.py
```

Если все настроено правильно, увидишь:
```
INFO - Бот запущен!
```

## Тестирование 🧪

### 1. Протестировать бота

1. Найди своего бота в Telegram (по имени, которое дал BotFather)
2. Отправь команду `/start`
3. Проверь, что появляется меню с кнопками
4. Нажми "🛒 Забрать вечную лицензию за 500₽"
5. Нажми "💳 Оплатить 500₽"
6. Нажми "✅ Да, протестировать!"
7. Должен прийти ключ от API

### 2. Проверить админ-команды

Отправь боту (от имени админа):
- `/stats` - статистика
- `/user ***REMOVED_ADMIN_ID***` - информация о пользователе (замени ID)
- `/give_key ***REMOVED_ADMIN_ID***` - выдать ключ вручную

## Структура базы данных 📊

База данных создается автоматически в `data/bot.db`:

**Таблица `users`:**
- `user_id` - ID пользователя Telegram
- `username` - username пользователя
- `has_license` - есть ли лицензия
- `license_key` - ключ лицензии
- `created_at` - дата регистрации

**Таблица `payments`:**
- `payment_id` - ID платежа
- `user_id` - ID пользователя
- `amount` - сумма платежа
- `status` - статус (pending/completed)
- `created_at` - дата платежа

## Возможные проблемы 🔍

**Бот не запускается:**
- Проверь, что все зависимости установлены
- Проверь, что `.env` файл существует и заполнен
- Проверь токен бота

**Ключи не генерируются:**
- Проверь `API_KEY` и `API_URL` в `.env`
- Проверь, что API сервер доступен и отвечает правильно
- Проверь логи бота на ошибки

**Админ-команды не работают:**
- Проверь `ADMIN_ID` в `.env` - должен быть твой реальный Telegram ID

## Поддержка 💬

Если что-то не работает:
1. Проверь логи бота
2. Проверь настройки `.env`
3. Убедись, что API сервер работает
