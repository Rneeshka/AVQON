# Admin Service

Отдельный FastAPI-сервис для административного интерфейса антивирусной системы.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Файл `.env` уже создан с базовыми настройками. Проверьте и при необходимости обновите значения:

**Важные переменные:**
- `DATABASE_URL` - URL базы данных (уже настроен из основного приложения)
- `ADMIN_JWT_SECRET` - Секретный ключ для JWT (ОБЯЗАТЕЛЬНО измените в production!)
- `ADMIN_ALLOWED_ORIGINS` - Разрешенные домены (включая avqonadmin.com и другие)
- `ADMIN_DEFAULT_PASSWORD` - Пароль по умолчанию (измените в production)
- `ADMIN_DANGER_ZONE_PASSWORD` - Пароль для опасной зоны

**Домены в CORS уже настроены:**
- `http://localhost:8001`
- `https://avqonadmin.com`
- `https://admin.avqon.com`
- `https://avqonadmin.avqon.com`
- И другие варианты

Если нужно добавить свои домены, отредактируйте `.env` файл.

### 3. Первоначальная настройка

```bash
python first_setup.py
```

Этот скрипт проверит:
- Подключение к базе данных
- Наличие необходимых таблиц
- Покажет информацию о пользователе по умолчанию

### 4. Запуск сервиса

#### Локально:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8001 --reload
```

#### Через Docker:
```bash
docker-compose up -d
```

Сервис будет доступен по адресу: http://localhost:8001

## 📋 Функциональность

### Страницы админ-панели:

1. **Дашборд** (`/`) - Обзор системы с ключевыми метриками
2. **Ключи API** (`/keys`) - Управление API ключами
3. **Угрозы** (`/threats`) - Управление базой угроз
4. **Кэш URL** (`/cache`) - Просмотр и управление кэшем
5. **IP репутация** (`/ip`) - Просмотр репутации IP адресов
6. **Логи** (`/logs`) - Просмотр логов запросов
7. **Опасная зона** (`/danger`) - Критические операции (требует пароль)

### API эндпоинты:

- `GET /health` - Health check
- `POST /api/auth/login` - Вход в систему
- `GET /api/auth/logout` - Выход из системы
- `GET /api/auth/me` - Информация о текущем пользователе

## 🔐 Аутентификация

Сервис использует JWT токены для аутентификации:
- Токены хранятся в cookie `admin_token`
- Токены действительны 24 часа (настраивается через `JWT_ACCESS_TOKEN_EXPIRE_MINUTES`)
- Для доступа к страницам требуется роль `viewer`, `moderator` или `admin`

### Роли:

- **admin** - Полный доступ ко всем функциям
- **moderator** - Доступ к управлению ключами и угрозами
- **viewer** - Только просмотр данных

## 🔧 Интеграция с основным приложением

## 🔒 Безопасность

- JWT токены с истечением срока действия
- Хеширование паролей (SHA-256 с солью)
- Rate limiting (10 запросов/сек по умолчанию)
- CORS настройка
- CSRF защита (через SameSite cookies)
- Логирование всех действий

## 📊 Мониторинг

- Health check endpoint: `GET /health`
- Логирование всех запросов через middleware
- Метрики времени обработки в заголовке `X-Process-Time`

## 📝 Примечания

- Пароль по умолчанию (`***REMOVED_ADMIN_DEFAULT_PASSWORD***`) должен быть изменен в production
- JWT секрет должен быть уникальным и безопасным
- Для production рекомендуется использовать HTTPS
- Redis опционален, но рекомендуется для кэширования

## 🐛 Устранение неполадок

### Ошибка подключения к БД:
- Проверьте `DATABASE_URL` в переменных окружения
- Убедитесь, что PostgreSQL доступен
- Проверьте права доступа пользователя БД

### Ошибка аутентификации:
- Проверьте `ADMIN_JWT_SECRET`
- Убедитесь, что cookie `admin_token` установлена
- Проверьте срок действия токена

### Страница не загружается:
- Проверьте логи сервиса
- Убедитесь, что порт 8001 свободен
- Проверьте CORS настройки
